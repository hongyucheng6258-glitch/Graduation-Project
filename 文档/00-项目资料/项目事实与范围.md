# 项目事实与范围

本文用于统一工程资料中的项目名称、事实口径和证据来源，供需求分析、设计说明和后续测试使用。

## 项目定位

项目名称为三维交互式智慧校园服务平台，界面展示名称为“梧桐校园”。系统面向高校学生的学习、生活与交流需求，由 Web 学生端、Web 管理后台、Spring Boot 后端、MySQL 和 Redis 组成。外部 DeepSeek 服务提供模型推理，Three.js 提供校园空间渲染。

典型任务包括参加活动、预约闲置物品、寻找失物、寻找学习伙伴、互助问答、发布动态、私信交流、整理错题和进入三维服务空间。管理员负责内容治理、公告、用户和系统配置。

## 能力边界

学号注册目前进行格式等校验，不等于接入学校真实学籍认证。学生、超级管理员和审核员账号属于项目账号体系。

三维校园是用于组织校园服务的虚拟空间。现有证据支持“空间化服务入口与业务复用”，没有提供真实校园测绘、建筑信息模型或物理环境实时同步数据。

AI 通过外部接口调用，工程贡献在请求编排、业务上下文、输出处理和功能集成。PDF 问答基于可提取文字的文档；浏览器 OCR 与 PDF 文本提取是两条不同流程。错题薄弱点报告主要是统计分析，不能与模型生成内容混为一谈。

校园向导包含示例静态信息，正式展示前需要替换或核验。推荐与估价依据候选业务数据及模型输出，不表示已经接入真实二手市场成交数据库。闲置模块提供预约和完成流程，未见独立支付结算系统。
