编制日期：2026 年 10 月 29 日。时间统一按 Asia/Shanghai 记录。各文档中的“已有实现”“本次验证”“待执行实验”和“改进建议”分别表示不同证据层级，引用时应保留这种区别。

## 使用这些材料

先以项目事实文档确定论述边界，再从需求、设计和实现资料中提炼自己的分析。图表应结合学校模板重新编号；流程中的状态和数据库枚举应保持一致。测试方案是执行依据，只有验证记录或后续实际执行日志可以作为测试结果。

数据库字典来自当前运行库的结构查询，字段说明结合 SQL 源码补充，不含业务记录、密码值、AI 密钥或登录令牌。接口清单来自 Controller 声明，DTO 附录来自请求类字段；仍需结合 Service 中的业务条件理解每个操作。

本次资料没有执行真实浏览器业务写入、外部 AI 调用或负载压测。相应实验需要在独立测试环境完成后再补充结果。
