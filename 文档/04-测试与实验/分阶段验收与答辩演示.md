## 复跑

在隔离环境中启用 Agent 和 RAG，导入校园演示资料并配置模型。独立测试环境关闭验证码校验。设置 `E2E_BACKEND_URL`、`E2E_STUDENT_WEB_URL`、`E2E_ADMIN_WEB_URL`、`E2E_ADMIN_PASSWORD` 和 `E2E_STUDENT_PASSWORD_FILE`。需要模拟活动草稿过期时，设置 `E2E_MYSQL_CONTAINER` 指向隔离的 MySQL 容器。浏览器回归使用 Playwright，可以用 `PLAYWRIGHT_PATH` 指定安装位置，用 `E2E_BROWSER_CHANNEL` 选择本机浏览器。

```powershell
mvn -B -f web/backend/pom.xml test
$tests = rg --files -g '*.test.mjs' web/frontend
node --test @tests
node tests/browser/e2e/search-and-assistant-ui.cjs
node tests/browser/e2e/agent-closure.cjs
node tests/browser/e2e/rag-eval.cjs
```

## 答辩演示顺序

1. 学生端进入校园向导，发送「帮我发布活动：《校园读书会》」。打开草稿，补地点和开始、结束时间后提交审核。
2. 管理端进入智能助手，查询待审活动，打开对应记录并核对。需要展示人工审核时，使用已进入待审核队列的演示活动。确认后回到学生端查看状态和通知。
3. 学生端搜索一件可预约的闲置，从向导发起预约，由另一个账号在「我的预约」处理。
4. 用公共知识库资料问答，打开页码引用。切换到个人 PDF，展示文档索引和问答。
5. 在管理端搜索校园动态，翻到第 2 页，打开结果后点击面包屑「搜索结果」。最后展示 3D 导览和校园业务入口。
