## 图表解释范围

ER 图主要表达逻辑关联。具体物理外键只有数据字典列出的关系，不能因为图中连线就声称数据库已经对所有关系实施外键约束。关系图省略部分字段，完整字段和索引见数据库设计文档。

用例图中的“发布者”是学生对具体资源的身份，图中让其继承学生角色以解释职责，不表示数据库新增一种用户角色。架构与部署图是设计表达，不包含未经验证的并发容量或可用性等级。

关键类图省略部分字段、参数、返回值与其他依赖，表达调用和数据访问关系；完整方法签名以源码为准。预约图只画当前流程可进入的状态，没有将尚未提供完整入口的取消枚举画为已交付流程。
